A program that writes one excuse an AI agent gives for missing a deadline — in the agent's own voice, deadpan, with the laugh landing at the end — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

The program writes exactly one excuse (at most 200 characters) to `/output/entry.txt`, deterministically, using only the Python standard library and no network access.
